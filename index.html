GITHUB BACKUP PROTOCOL MANUAL & SECURE

To maintain long-term archives without transmitting tokens or storing API keys in client-side code:

  1. Click EXPORT BACKUP (JSON) to save your current database.
  2. Rename the downloaded file to habits-backup.json.
  3. Commit and push the file to your private GitHub repository under /backup/habits-backup.json.
  4. When switching devices or rebuilding your local database, simply load that JSON file via RESTORE FROM JSON.
